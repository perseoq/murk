# ADR 0005 — Licencia GPL-3.0-or-later

- **Estado:** aceptado
- **Fecha:** 2026-11-19

## Contexto

El proyecto nace como alternativa libre a un editor propietario. Se quiere garantizar que las mejoras sigan siendo libres y que el código pueda integrarse con el ecosistema Linux.

## Decisión

Licenciar Murk bajo **GNU GPL v3.0 o posterior**.

## Motivos

1. Compatible con las dependencias previstas (MIT, Apache-2.0, LGPL).
2. Impide forks propietarios del editor.
3. Alineado con el escritorio Linux y con proyectos como GIMP/Inkscape.
4. Permite distribución en Fedora/Flathub.

## Consecuencias

**Positivas**
- Libertad para usuarios y contribuyentes.
- Compatibilidad con la mayoría de librerías del stack.

**Negativas**
- No se puede enlazar con código GPL-2.0-only ni propietario.
- Obliga a publicar el código de cualquier binario distribuido.
- Algunas empresas evitan GPL para uso interno modificado (aunque no se distribuye).

## Reglas

1. Header SPDX en todos los archivos.
2. `LICENSE.md` incluido en cada release y paquete.
3. Revisión de licencias de dependencias en cada PR (`NOTICE.md`).
4. Las contribuciones se aceptan bajo la misma licencia (DCO).
5. No se incorporan assets de Typora ni de otros productos propietarios.

## Alternativas descartadas

| Alternativa | Motivo |
|---|---|
| MIT | Permite forks propietarios |
| Apache-2.0 | No garantiza reciprocidad |
| AGPL | Enfocada a red; innecesaria para una app local |
| MPL-2.0 | Reciprocidad por archivo, más laxa |
