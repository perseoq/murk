# 23 — Glosario

| Término | Definición |
|---|---|
| **AST** | Árbol de sintaxis abstracta del Markdown. |
| **Atomic range** | Rango de CM6 que el cursor no puede atravesar carácter a carácter. |
| **CM6** | CodeMirror 6, el editor usado por Murk. |
| **CRLF** | Fin de línea `\r\n` (Windows). |
| **Decoration** | Marca visual de CM6 (clase, reemplazo o widget) que no altera el documento. |
| **Dirty** | Documento con cambios sin guardar. |
| **EOL** | End of line; convención de fin de línea. |
| **Frontmatter** | Bloque de metadatos al inicio del documento (`---`). |
| **GFM** | GitHub Flavored Markdown. |
| **Hito (M)** | Entrega planificada del proyecto. |
| **IME** | Input Method Editor (composición de caracteres CJK, etc.). |
| **IPC** | Comunicación entre la WebView y el núcleo Rust. |
| **KaTeX** | Biblioteca de renderizado matemático. |
| **Lezer** | Parser incremental usado por CM6. |
| **Live preview** | Vista formateada sobre el propio Markdown, sin panel separado. |
| **Mermaid** | Biblioteca de diagramas a partir de texto. |
| **Murk** | Nombre de este proyecto. |
| **P0/P1/P2** | Prioridad de paridad funcional. |
| **Pandoc** | Conversor universal de documentos usado para exportar. |
| **Recovery snapshot** | Copia temporal del documento para recuperación tras fallo. |
| **Reveal-on-cursor** | Mostrar la sintaxis de un nodo cuando el cursor entra en él. |
| **Scope** | Permiso de acceso a una ruta concreta. |
| **Sidecar** | Proceso externo empaquetado o invocado (Pandoc, Chromium). |
| **SPDX** | Identificador estándar de licencia en cabeceras de archivo. |
| **Tauri** | Framework de apps de escritorio usado por Murk. |
| **Watcher** | Servicio que observa cambios en el sistema de archivos. |
| **Widget** | Elemento interactivo insertado por CM6 en lugar de un rango de texto. |
| **Workspace** | Carpeta raíz abierta y sus archivos. |
